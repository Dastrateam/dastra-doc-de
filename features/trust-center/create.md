# Ein Trust Center erstellen

Sie können ein Trust Center über die Startseite der Trust-Center-Funktion erstellen, indem Sie auf "Trust Center erstellen" klicken. Diese Option kann gesperrt sein, wenn Sie das Trust-Center-Kontingent Ihres Plans bereits erreicht haben.

<figure><img src="../../.gitbook/assets/create hub.png" alt=""><figcaption><p>Erstellen Sie ein Privacy Hub, indem Sie auf 'Privacy-Hub erstellen' klicken</p></figcaption></figure>

Sie müssen einen Namen und eine Organisationseinheit angeben, um die Erstellung Ihres Trust Centers abzuschließen

<figure><img src="../../.gitbook/assets/image (303).png" alt=""><figcaption><p>Ein Privacy-Hub erstellen</p></figcaption></figure>

Sobald das Trust Center erstellt ist, werden Sie zur Bearbeitungsseite Ihres Trust Centers weitergeleitet

<figure><img src="../../.gitbook/assets/edit privacy center.png" alt=""><figcaption><p>Die Bearbeitungsseite eines Trust Centers</p></figcaption></figure>
