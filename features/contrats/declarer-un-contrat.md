# Einen Vertrag erfassen

Sie können einen neuen Vertrag erfassen, indem Sie auf die Schaltfläche "Vertrag erstellen" auf der Hauptseite des Moduls **Verträge** klicken.

<figure><img src="../../.gitbook/assets/image (319).png" alt=""><figcaption><p>Erfassen Sie Ihren ersten Vertrag, indem Sie auf 'Vertrag erstellen' klicken</p></figcaption></figure>

Sie können wählen, ob Sie von Grund auf neu beginnen oder einen Vertrag aus einer unserer [dynamischen Vertragsvorlagen](modeles-de-contrats-dynamiques.md) generieren möchten.

<figure><img src="../../.gitbook/assets/image (364).png" alt=""><figcaption><p>Die Optionen zur Vertragserstellung</p></figcaption></figure>

Wenn Sie von Grund auf neu beginnen, müssen Sie lediglich Ihrem Vertrag einen Namen geben, Ihren Anhang hochladen (Sie können den Anhang auch später nach der Vertragserfassung hochladen) und ihn einer Organisationseinheit zuweisen.\
<br>
