# Verwaltung von Tags

## Wozu dienen Tags

Tags dienen dazu, Informationen nach Ihrer eigenen Methodik zu klassifizieren. Sie ermöglichen es, Verarbeitungen oder andere Elemente in Dastra hervorzuheben, um sie von der Masse abzuheben.&#x20;

So können Sie beispielsweise einen Tag "prioritär" oder "Zu überprüfen" oder "sensible Verarbeitung" vergeben, um die betreffenden Verarbeitungen oder anderen Elemente leicht wiederzufinden. Die Tag-Liste ist unbegrenzt. Sie können mehrere Tags pro Verarbeitung vergeben. Durch Klicken auf einen Tag filtern Sie automatisch die Verarbeitungen, die diesen Tag tragen.

## Wie erstellt man Tags?

Beginnen Sie im Tag-Eingabeformular, den Namen eines beliebigen Tags einzutippen. Es gibt zwei Möglichkeiten: Entweder existiert der Tag bereits, dann können Sie ihn auswählen. Falls er nicht existiert, können Sie **die Eingabetaste auf Ihrer Tastatur drücken**, wodurch der neue Tag automatisch erstellt und zur Auswahlliste hinzugefügt wird.
