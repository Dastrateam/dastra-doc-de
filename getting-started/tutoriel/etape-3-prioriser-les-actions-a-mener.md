# Schritt 4: Die durchzuführenden Maßnahmen priorisieren

Sobald das Verarbeitungsverzeichnis erstellt ist, listen Sie auf dessen Grundlage [alle durchzuführenden Aufgaben](https://www.cnil.fr/fr/prioriser-les-actions-mener) auf, um den aktuellen und künftigen Verpflichtungen der Datenschutz-Grundverordnung (DSGVO) nachzukommen. Dann priorisieren Sie diese Maßnahmen anhand der Risiken, die Ihre Verarbeitungen für die Rechte und Freiheiten der betroffenen Personen darstellen.

{% hint style="info" %}
Sie wissen nicht, mit welchen Maßnahmen Sie beginnen sollen? Sehen Sie sich den [Leitfaden zur Sicherheit personenbezogener Daten](https://www.cnil.fr/fr/principes-cles/guide-de-la-securite-des-donnees-personnelles) der CNIL an, der einen guten Ausgangspunkt darstellt.
{% endhint %}

Nachdem die für Ihr Compliance-Projekt erforderlichen Maßnahmen identifiziert sind, erstellen Sie die zugehörigen Aufgaben und weisen sie den entsprechenden Mitarbeitern direkt im Tab "Planung" des Dastra-Tools zu:
